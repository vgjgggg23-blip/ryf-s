# موقع المتجر المرتبط بديسكورد

موقع عربي متعدد الصفحات مع بوت ديسكورد ولوحة تحكم.

## ماذا يفعل

- تسجيل الدخول بحساب ديسكورد.
- التقييمات: يقيّم من يملك رتبة العملاء فقط. يظهر التقييم في الموقع ويُرسل إلى قناة في الديسكورد. ويمكن أيضًا التقييم من الديسكورد بالأمر `/review`.
- الإدارة: تضيف رقم العضو ورقم رتبته من لوحة التحكم، فيظهر اسمه وصورته ورتبته من الديسكورد تلقائيًا.
- شركاء النجاح: تلصق رابط دعوة السيرفر، فتظهر صورته وبنره واسمه وعدد أعضائه والمتصلين.
- حساباتنا: فارغة في البداية، وتضيف كل حساب باسمه وصورته ورابطه.
- الرئيسية: بنر المتجر وصورته وصورة الموقع وبنره.
- زر "سيرفر المتجر على ديسكورد" في الرئيسية يفتح رابط الدعوة.
- لوحة التحكم `/admin`: الألوان الستة والنصوص والصور وكل القوائم والتقييمات.

## خطوات التشغيل

### 1) تجهيز تطبيق الديسكورد
1. افتح https://discord.com/developers/applications واضغط New Application.
2. من قائمة Bot: اضغط Reset Token وانسخ التوكن، وفعّل **Server Members Intent**.
3. من قائمة OAuth2: انسخ Client ID و Client Secret.
4. في OAuth2 > Redirects أضف: `رابط_موقعك/auth/callback` (مثال: `https://your-domain.com/auth/callback`).
5. أضف البوت لسيرفرك: OAuth2 > URL Generator، اختر `bot` و `applications.commands`، وصلاحيات: View Channels, Send Messages, Embed Links، ثم افتح الرابط الناتج.
6. في إعدادات ديسكورد > متقدم فعّل Developer Mode. بعدها كليك يمين على السيرفر أو الرتبة أو القناة أو حسابك واختر Copy ID.

### 2) إعداد المشروع
```
cp .env.example .env
```
املأ ملف `.env`: التوكن، Client ID، Client Secret، رقم السيرفر `DISCORD_GUILD_ID`، رابط موقعك `SITE_URL`، وضع رقم حسابك في `ADMIN_IDS`.

### 3) التشغيل
```
npm install
npm start
```
افتح الموقع، سجّل الدخول، ثم ادخل `/admin`.

## بعد التشغيل (من لوحة التحكم)
1. الألوان: اختر الألوان الستة.
2. الصور: ارفع بنر المتجر وصورته وصورة الموقع وبنره.
3. التقييمات: ضع رقم رتبة العملاء ورقم قناة نشر التقييمات.
4. الإدارة: أضف رقم العضو ورقم رتبته.
5. الشركاء: ألصق روابط دعوة السيرفرات.

## المظهر (نيون + نجوم تفاعلية)
- ملفات المظهر: `public/neon.css` (التوهج والزجاج والحركات) و`public/fx.js` (النجوم المتحركة).
- النجوم تتحرك مع الماوس: تبتعد عنه وتتوهج وتتصل بخطوط نيون، مع شهب عشوائية وشرارات عند النقر، وإضاءة تتبع المؤشر داخل البطاقات.
- كل ألوان النيون تُؤخذ من الألوان الستة في لوحة التحكم، فغيّرها وسيتغير التوهج والنجوم تلقائيًا (`accent` و`gold` هما لونا النيون).
- الألوان الافتراضية الجديدة تُطبَّق على التشغيل الأول فقط. إذا كان عندك ملف `data/db.json` قديم فاختر الألوان من لوحة التحكم.
- الحركة تتوقف تلقائيًا لمن فعّل «تقليل الحركة» في جهازه.

## ملاحظات
- البيانات والصور تُحفظ في مجلد `data`. إذا استضفت على خدمة تمسح الملفات عند إعادة التشغيل، اربط المجلد بقرص دائم (Volume) أو غيّر `DATA_DIR`.
- لا تشارك ملف `.env` مع أحد.
- لكل عضو تقييم واحد كل 24 ساعة، وتقدر تخفي أو تحذف أي تقييم من اللوحة.
- المشروع يحتاج Node.js 18 أو أحدث.
